# centerless-grinding-affine
Physics-based and data-driven modeling of centerless grinding as an affine profile transformation

## 📄 Related Publication

This repository is associated with the following research paper:

**Centerless grinding as an affine profile transformation: Physics-based and data-driven approaches**

- **Journal:** *Journal of Manufacturing Processes*
- **DOI:** [10.1016/j.jmapro.2026.05.081](https://doi.org/10.1016/j.jmapro.2026.05.081)
- **Published article:** [Read the paper on ScienceDirect](https://www.sciencedirect.com/science/article/pii/S1526612526005505)

This repository provides MATLAB code for physics-based and data-driven modelling of centerless grinding dynamics as an affine profile transformation.

Please cite the original publication when using this implementation in academic research.
